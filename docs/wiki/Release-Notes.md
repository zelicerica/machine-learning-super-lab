# Release notes

[Wiki home](Home.md) · [Repository README](../../README.md)

**Full-stack Transformer release `2026.11-transformer.3`:** The 3D explorer now displays all six encoder and six decoder layers, with 63 individual component blocks. Open any numbered layer for its detailed computation, trace residual and final-encoder memory connections, or step through the whole model. The dark palette, numerical attention activity, and security/setup updates from the preceding release are preserved. See [implementation and verification](../Transformer-Explorer.md).

**Transformer Explorer release `2026.11-transformer.1`:** Lesson 59 adds a local 3D Transformer schematic with orbit, pan, zoom, component inspection, and a causal-mask calculation. The separate lesson traces the 2017 paper through BERT, GPT-3, vision, and instruction tuning, with seven annotated sources. Existing lesson IDs and numbers remain stable. See [implementation and dated verification](../Transformer-Explorer.md), including the outstanding browser visual review.

**Content-reviewed release `2026.11-midnight.4`:** all 58 lessons have matched references at the end, the 18 Foundations implementations have individual worked-example illustrations, and shared workflow material has been consolidated. Read the [lesson-by-lesson audit](../../CONTENT-AUDIT.md) and [annotated references](../../course/Annotated-Lesson-References.md).

**Midnight Motion release:** the connected glass blocks now move behind the lab as a locally bundled, silent MP4. The landing page gives the video room to show; lesson backgrounds are dimmed for reading. Use **Pause motion** in the top bar; the preference persists, and reduced-motion settings are respected. The navy workspace also includes coding colors, a light-theme option, searchable learning tracks, readable lesson outlines, code highlighting, expandable diagrams, controlled teaching animations, and a searchable research timeline. Click the lesson-count badge to see the exact release and folder serving your browser.

**Lesson order:** Foundations **1–20**, Language models **21–34**, Build and retrieve **35–42**, and Modern language engineering **43–58**. Numbering, headings, and Next links follow this sequence. Existing lesson links, saved completion, and notes remain valid. The standalone language workbook retains its own Lab 0–13 numbering. Green text accents replace the bright blue lettering in both themes.

**Still seeing 34 lessons locally?** Your launcher may be running an older extracted copy. Follow [Upgrade to Midnight](../../UPGRADE.md) to switch folders while preserving your environment, outputs, notes, and progress.

The older notes above describe release `2026.11-midnight.4`; see [Verification](../../VERIFICATION.md) for dated execution evidence. Documentation restructuring does not change the application release or assert that separate security updates have been completed.
